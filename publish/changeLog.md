# 洛雪增强版 v1.9.1

基于 lyswhut/lx-music 系列项目及 lx-music-mobile 二次开发，采用 Apache-2.0 许可证，保留上游版权声明，修改说明见 NOTICE。

- 不内置任何音源、固定音源地址或推荐来源；首次启动列表为空。
- 支持用户本地导入、在线导入，以及自定义源排序和删除。
- 多源自动切换默认关闭，仅在用户已导入的源之间按列表顺序重试。
- 订阅地址默认为空；用户保存一次后重启仍保留，源失效时自动检查更新，限次重试。
- 提供 arm64-v8a、armeabi-v7a、x86_64、x86 和 universal 五种 APK。

APK 使用开发测试签名。版本名称为 v1.9.1；内部版本代码保留为 79。

本软件不提供任何音源，用户导入的内容由用户自行负责，请遵守当地法律与版权。
